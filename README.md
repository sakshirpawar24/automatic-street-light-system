
# Automatic Street Light System Using Arduino

## Project Overview

The Automatic Street Light System is an Arduino-based automation project designed to control street lights according to surrounding light conditions.

The system uses an LDR sensor to detect ambient light and an IR sensor to detect movement. Based on sensor inputs, the Arduino controls the street light automatically.

The main objective is to reduce unnecessary electricity consumption and minimize manual operation.

## Objectives

- Automatically control street lights.
- Detect day and night conditions using an LDR sensor.
- Detect movement using an IR sensor.
- Reduce unnecessary energy consumption.
- Improve lighting automation and efficiency.

## Components Used

- Arduino UNO
- LDR Sensor
- IR Sensor
- LEDs / Bulbs
- Breadboard
- USB A to B Cable
- Connecting Wires

## Working Principle

1. The LDR sensor detects surrounding light intensity.
2. During daytime, the street light remains OFF.
3. During darkness, the Arduino checks the IR sensor input.
4. When movement is detected, the street light turns ON.
5. When movement is not detected, the light remains OFF.
